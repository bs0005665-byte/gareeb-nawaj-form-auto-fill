# Gareeb Nawaj - Form Auto Fill

## Run
This is a static website. Because browsers restrict local PDF fetches, serve the folder with a simple local server or upload it to GitHub Pages / Cloudflare Pages.

Example:
python -m http.server 8080
Then open http://localhost:8080

## First-time setup
1. Fill common customer details.
2. Choose a form.
3. Click + Custom Field.
4. Drag the text to the correct blank position in the PDF preview.
5. Choose field, text size/style, then Apply.
6. Repeat for required fields/pages and click Save Setting.
7. Next customers reuse the saved mapping in that browser.

Includes the five PDFs supplied in the conversation.
